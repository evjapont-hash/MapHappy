The MapHappy desktop app for Windows (64-bit).

1. Download **MapHappy-windows.zip** below and unzip it.
2. Run **MapHappy.exe** in the folder. There is nothing to install.
3. To try it, choose *File > Open...* and pick `example/show.maphappy`.

Windows may warn that the app isn't recognised, because it isn't code-signed: choose *More info > Run anyway*.
It needs a graphics card with OpenGL 3.3.

No download needed: the [web editor](https://evjapont-hash.github.io/MapHappy/editor.html) runs in the browser.
